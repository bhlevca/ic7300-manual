## [1.0.0] - 2026-01-28

### Added
- Initial release of IC-7300 Interactive Manual
- Streamlit-based web application
- Tabbed navigation interface for major sections
- Interactive SVG diagrams for front and rear panels
- Chapter-based documentation system with expandable sections
- Step-by-step wizards for common procedures:
  - First Power On
  - Using the Antenna Tuner
  - FT8/WSJT-X Setup
  - Changing Bands
- Full-text search functionality
- Quick reference tables:
  - Band Frequencies
  - Button Shortcuts
  - Menu Tree
- Comprehensive documentation for:
  - Introduction to IC-7300
  - Front Panel controls
  - Rear Panel connections
  - Basic Operations
  - Antenna & SWR
  - Digital Modes
  - WSJT-X / FT8 setup
- Responsive design with sidebar navigation
- Dark mode toggle (UI only)

### Technical
- Python 3.9+ compatibility
- Modern pyproject.toml configuration
- Modular component architecture
- Markdown-based content system
