# Button Shortcuts Quick Reference

This quick reference covers all button functions and shortcuts on the IC-7300.

## Power and Control Buttons

| Button | Short Press | Long Press (1 sec) |
|--------|-------------|-------------------|
| **POWER** | - | Toggle ON/OFF |
| **TRANSMIT** | Toggle TX/RX | - |
| **VOX/BK-IN** | Toggle VOX mode | - |
| **TUNER** | Enable/disable tuner | Start auto-tune |

## Navigation Buttons

| Button | Short Press | Long Press |
|--------|-------------|------------|
| **MENU** | Open MENU screen | - |
| **FUNCTION** | Cycle FUNCTION screens | - |
| **SCOPE** | Cycle scope modes | - |
| **QUICK** | Open QUICK menu | - |
| **EXIT** | Back one level | Exit to main |

## Mode Buttons

| Button | First Press | Second Press | With DATA |
|--------|-------------|--------------|-----------|
| **SSB** | USB mode | LSB mode | USB-D / LSB-D |
| **CW** | CW mode | CW-R mode | - |
| **RTTY** | RTTY mode | RTTY-R mode | - |
| **AM** | AM mode | - | AM-D |
| **FM** | FM mode | - | FM-D |

## Memory Buttons

| Button | Short Press | Long Press |
|--------|-------------|------------|
| **VFO/MEMO** | Toggle VFO/Memory | - |
| **MW** | Write to memory | - |
| **V/M** | Copy VFO to Memory | - |
| **M-CH** | Memory channel mode | - |
| **MPAD** | Recall memo pad | Save to memo pad |

## Other Buttons

| Button | Short Press | Long Press |
|--------|-------------|------------|
| **XFC** | Monitor TX frequency | - |
| **SPLIT** | Toggle split mode | - |
| **A/B** | Swap VFO A/B | - |
| **CLEAR** | Clear RIT/XIT | - |
| **RIT** | Toggle RIT | - |
| **XIT** | Toggle XIT | - |

## Main Dial Functions

| Action | Function |
|--------|----------|
| Rotate slow | Fine tuning |
| Rotate fast | Rapid tuning |
| Push | Access MULTI options |

## MULTI Knob (Context Sensitive)

When MULTI is pressed, available options appear on screen:

### SSB Mode
- RF POWER
- MIC GAIN
- VOX GAIN
- ANTI VOX
- VOX DELAY

### CW Mode
- RF POWER
- KEY SPEED
- SIDETONE
- CW PITCH

### RTTY Mode
- RF POWER
- TX SHIFT

### FM Mode
- RF POWER
- MIC GAIN

## Touch Screen Quick Actions

| Area Touched | Action |
|--------------|--------|
| MHz digits | Band/frequency entry |
| Mode display | Mode options |
| S-meter area | Change meter type |
| Spectrum scope | Tune to that frequency |
| Memory channel | Select memory |
| VFO A/B | Switch VFOs |

## Function Screen (F1-F5)

Press FUNCTION repeatedly to access:

### Function Screen 1
- NB (Noise Blanker)
- NR (Noise Reduction)
- NOTCH
- COMP (Compressor)
- VOX

### Function Screen 2
- AGC
- METER
- SPLIT
- RIT
- XIT

### Function Screen 3
- MONITOR
- MONI GAIN
- MN-Q (Monitor Quality)
- TONE
- TSQL

### Function Screen 4
- IF Filter
- SHARP/SOFT
- TPF
- RTTY/PSK decode
- VOICE TX

## Emergency/Protection Features

| Function | Access |
|----------|--------|
| Reset to defaults | MENU > SET > Others > Reset |
| Emergency tuner | MENU > SET > Function > Tuner (Emergency) |
| Protection status | TX meter shows if power reduced |
| SWR protection | Automatic - reduces power if SWR high |
