# Band Frequencies Quick Reference

Complete frequency reference for HF and 6m amateur bands with common operating frequencies.

| Band | Frequency Range | Primary Use |
|------|-----------------|-------------|
| 160m | 1.800 - 2.000 MHz | Night propagation |
| 80m | 3.500 - 4.000 MHz | Night/regional |
| 60m | 5 channels | Secondary, channelized |
| 40m | 7.000 - 7.300 MHz | Night DX / Day regional |
| 30m | 10.100 - 10.150 MHz | CW/Digital only |
| 20m | 14.000 - 14.350 MHz | Daytime DX |
| 17m | 18.068 - 18.168 MHz | Daytime DX |
| 15m | 21.000 - 21.450 MHz | Daytime DX |
| 12m | 24.890 - 24.990 MHz | Daytime DX |
| 10m | 28.000 - 29.700 MHz | Sporadic E / Solar max |
| 6m | 50.000 - 54.000 MHz | VHF propagation |

| Band | Best Time | Typical Range |
|------|-----------|---------------|
